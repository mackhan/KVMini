# 需求文档：角色自由切换修复

## 引言

当前 KVMini 的角色切换逻辑存在设计缺陷：Mac 端"切换为主控端"被实现为"主动连接 Windows"，而"切换为被控端"被实现为"监听等待连接"。这导致角色切换与连接方向强绑定，无法真正实现"随意切换"。

**正确的设计应该是：**
- 两端（Mac/Windows）**始终同时监听 8889 端口**，随时可以接受对方连接
- **主控端**：负责采集本机键鼠输入，发送给对端执行
- **被控端**：负责接收对端发来的键鼠事件，在本机执行
- 角色切换只改变"谁采集发送、谁接收执行"，**不改变连接方向**
- 连接建立后，通过握手协议协商双方角色

**默认配置：**
- Mac 端默认 IP：`30.19.140.39`，默认角色：被控端
- Windows 端默认 IP：`30.19.24.43`，默认角色：主控端

---

## 需求

### 需求 1：双端同时监听

**用户故事：** 作为用户，我希望两台电脑都能随时接受对方的连接请求，以便不需要关心谁先启动、谁主动连接。

#### 验收标准

1. WHEN Mac 端启动 THEN 系统 SHALL 在 8889 端口监听 TCP 连接，无论当前角色是主控端还是被控端
2. WHEN Windows 端启动 THEN 系统 SHALL 在 8889 端口监听 TCP 连接，无论当前角色是主控端还是被控端
3. WHEN 一端主动连接对端 THEN 系统 SHALL 通过握手协议协商双方角色（发起方为主控端，接受方为被控端）
4. IF 已有连接存在 THEN 系统 SHALL 断开旧连接后再建立新连接

---

### 需求 2：角色切换不绑定连接方向

**用户故事：** 作为用户，我希望随时切换主控/被控角色，以便灵活控制哪台电脑的键鼠操作哪台电脑。

#### 验收标准

1. WHEN 用户在 Mac 端触发"切换为主控端" THEN 系统 SHALL 主动连接 Windows 端（`30.19.24.43:8889`），发起握手声明自己为主控端
2. WHEN 用户在 Mac 端触发"切换为被控端" THEN 系统 SHALL 断开当前主控连接，回到监听状态，等待 Windows 端连接
3. WHEN 用户在 Windows 端触发"切换为主控端" THEN 系统 SHALL 主动连接 Mac 端（`30.19.140.39:8889`），发起握手声明自己为主控端
4. WHEN 用户在 Windows 端触发"切换为被控端" THEN 系统 SHALL 断开当前主控连接，回到监听状态，等待 Mac 端连接
5. WHEN 握手完成 THEN 系统 SHALL 主控端开始采集并发送键鼠事件，被控端开始接收并执行键鼠事件

---

### 需求 3：IP 配置正确

**用户故事：** 作为用户，我希望两端的默认 IP 配置正确，以便开箱即用，不需要手动配置。

#### 验收标准

1. WHEN Mac 端（kvm-agent）需要连接对端 THEN 系统 SHALL 默认使用 Windows 端 IP `30.19.24.43`
2. WHEN Windows 端（src-tauri）需要连接对端 THEN 系统 SHALL 默认使用 Mac 端 IP `30.19.140.39`
3. WHEN Mac 端启动 THEN 系统 SHALL 显示"Mac IP: 30.19.140.39，Windows IP: 30.19.24.43"
4. IF 用户未指定 IP THEN 系统 SHALL 使用上述默认 IP 进行连接

---

### 需求 4：屏幕边缘触发角色切换

**用户故事：** 作为用户，我希望鼠标移动到屏幕边缘时自动切换控制权，以便无缝在两台电脑间切换。

#### 验收标准

1. WHEN Mac 处于被控端模式且鼠标移动到配置的边缘（默认右边缘） THEN 系统 SHALL 触发 Mac 切换为主控端，连接 Windows
2. WHEN Mac 处于主控端模式且鼠标移动到配置的边缘（默认左边缘） THEN 系统 SHALL 触发 Mac 切换为被控端，断开连接
3. WHEN Windows 处于主控端模式且鼠标移动到配置的边缘（默认右边缘） THEN 系统 SHALL 触发 Windows 切换为被控端
4. WHEN Windows 处于被控端模式且鼠标移动到配置的边缘（默认左边缘） THEN 系统 SHALL 触发 Windows 切换为主控端，连接 Mac
5. WHEN 边缘触发发生 THEN 系统 SHALL 有防抖处理（50ms 内不重复触发）

---

### 需求 5：快捷键触发角色切换

**用户故事：** 作为用户，我希望通过快捷键随时切换角色，以便在不移动鼠标的情况下切换控制权。

#### 验收标准

1. WHEN 用户按下 Ctrl+Alt+K THEN 系统 SHALL 在主控端和被控端之间切换
2. WHEN 切换成功 THEN 系统 SHALL 显示系统通知告知当前角色
3. WHEN 切换失败（如连接超时） THEN 系统 SHALL 显示错误通知并保持原角色

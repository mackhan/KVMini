# 实施计划：键鼠共享核心功能

- [ ] 1. 定义事件传输协议与数据结构
   - 在 `src-tauri/src/` 新建 `protocol.rs`，定义二进制帧格式（事件类型枚举、鼠标/键盘事件结构体）
   - 实现序列化/反序列化方法，使用固定长度帧，无 JSON 开销
   - 编写协议编解码单元测试（覆盖 macOS 和 Windows 字节序一致性）
   - _需求：6.1、6.5_

- [ ] 2. 实现被控端 TCP 服务（Rust 后端）
   - 在 `src-tauri/src/` 新建 `server.rs`，实现 TCP 监听服务（默认 0.0.0.0:8889）
   - 设置 TCP_NODELAY，实现握手协议（版本号、平台信息交换）
   - 接收事件流并解码，分发给平台注入模块
   - 编写 TCP 服务单元测试（连接建立、握手、断线处理）
   - _需求：2.1、2.2、6.2、6.4_

- [ ] 3. 实现平台事件注入模块（macOS + Windows）
   - 在 `src-tauri/src/` 新建 `injector.rs`，定义统一注入接口 `trait EventInjector`
   - macOS 实现：使用 `CGEvent` API 注入鼠标移动、点击、键盘事件（`#[cfg(target_os = "macos")]`）
   - Windows 实现：使用 `SendInput` API 注入事件（`#[cfg(target_os = "windows")]`），处理 DPI 坐标归一化
   - 为 macOS 和 Windows 各自编写独立单元测试
   - _需求：2.3、2.4、2.5、8.1、8.5_

- [ ] 4. 实现主控端键鼠捕获模块（macOS + Windows）
   - 在 `src-tauri/src/` 新建 `capturer.rs`，定义统一捕获接口 `trait EventCapturer`
   - macOS 实现：使用 `CGEvent Tap` 捕获全局键鼠事件，支持拦截本机响应（`#[cfg(target_os = "macos")]`）
   - Windows 实现：使用 `SetWindowsHookEx`（WH_MOUSE_LL、WH_KEYBOARD_LL）低级钩子（`#[cfg(target_os = "windows")]`）
   - 实现鼠标移动事件节流（最高 1000Hz），快捷键 Ctrl+Alt+S 退出控制模式
   - 编写事件捕获与序列化单元测试（macOS 和 Windows 分支）
   - _需求：3.1、3.2、3.3、3.4、3.5、3.6、6.3、8.2_

- [ ] 5. 实现主控端 TCP 发送与断线重连
   - 在 `src-tauri/src/` 新建 `client.rs`，实现 TCP 连接管理与事件发送
   - 集成已有断线重连逻辑，发送失败时自动重连，不丢失连接状态
   - 编写发送逻辑单元测试（正常发送、断线重连场景）
   - _需求：3.7、3.8_

- [ ] 6. 实现屏幕边缘检测与控制权切换逻辑
   - 在 `src-tauri/src/` 新建 `edge_switch.rs`，实现屏幕边缘检测（上/下/左/右）
   - 根据显示器布局配置决定切换方向，切换时隐藏/显示鼠标光标
   - 向被控端发送"切换控制权"协议帧，被控端在对应边缘位置显示鼠标
   - 编写边缘检测单元测试（macOS 和 Windows 坐标系差异）
   - _需求：4.1、4.2、4.3、4.4、4.6_

- [ ] 7. 实现多显示器布局配置（前端 UI + 后端持久化）
   - 前端新增"显示器布局"配置页面，两个可拖拽的显示器方块，支持左/右/上/下四方向放置
   - 布局变更时调用 Tauri 命令保存配置到本地文件（macOS 和 Windows 均支持）
   - 后端实现布局配置读取/保存命令，供边缘切换模块使用
   - 编写布局配置保存/读取和边缘映射逻辑的单元测试
   - _需求：5.1、5.2、5.3、5.4、5.5、5.6_

- [ ] 8. 实现主控端/被控端角色切换 UI 与 Tauri 命令
   - 前端主界面新增角色切换按钮（主控端 / 被控端），显示当前角色和连接状态
   - 后端实现 `set_role` Tauri 命令，切换角色时停止旧服务、启动新服务、断开所有连接
   - 延迟 > 50ms 时在 UI 显示延迟警告
   - 编写角色切换逻辑的前端和后端测试
   - _需求：1.1、1.2、1.3、1.4、1.5、4.5_

- [ ] 9. 实现 macOS 辅助功能权限检测与引导
   - 后端实现 `check_accessibility_permission` Tauri 命令（macOS 检测权限，Windows 直接返回已授权）
   - 前端在应用启动时调用权限检测，未授权时显示引导提示和"去开启"按钮（跳转系统偏好设置）
   - 用户授权返回后自动重新检测并更新 UI
   - 编写权限检测逻辑的 macOS 和 Windows 分支测试
   - _需求：2.7、2.8、7.1、7.2、7.3、7.4、7.5_

- [ ] 10. 集成测试与跨平台验证
   - 编写端到端集成测试：主控端捕获 → 协议编码 → TCP 发送 → 协议解码 → 被控端注入全链路
   - 验证 macOS ↔ Windows 互控场景（事件类型、坐标系、延迟）
   - 验证屏幕边缘切换和显示器布局配置在两个平台上的一致性
   - _需求：2.9、3.8、8.3、8.4_

# 实施计划：权限引导强制化 & 手动连接 UI 修复

- [ ] 1. 移除权限横幅关闭按钮，改为强制显示
   - 在 `src/index.html` 或 `src/main.js` 中找到权限横幅的 ✕ 关闭按钮，将其删除
   - 确保横幅在权限为 `Denied` 时始终显示，不可被用户手动关闭
   - 确保扫描和连接按钮不受横幅影响，保持正常可用状态
   - _需求：1.1、1.2_

- [ ] 2. 修复权限轮询逻辑，权限授予后自动隐藏横幅
   - 确认 `checkAccessibilityPermission` 函数每 2 秒轮询一次
   - WHEN 轮询检测到 `Granted` THEN 自动隐藏横幅并停止轮询
   - IF 平台为 Windows THEN 不显示横幅（跳过轮询）
   - _需求：1.4、1.5、1.6_

- [ ] 3. 连接成功后检查权限并提示用户
   - 在连接成功的回调中，调用 `check_accessibility_permission` 检查当前权限状态
   - IF 权限为 `Denied` THEN 在连接状态区域显示提示文字，并禁用"开始共享"按钮
   - IF 权限为 `Granted` THEN 正常显示"开始共享"按钮
   - IF 平台为 Windows THEN 跳过权限检查，直接启用"开始共享"按钮
   - _需求：2.1、2.2、2.4_

- [ ] 4. 权限授予后动态恢复"开始共享"按钮
   - 在权限轮询成功（`Granted`）的回调中，同时移除连接状态区域的权限提示
   - 恢复"开始共享"按钮的可用状态
   - _需求：2.3_

- [ ] 5. 修复手动连接 IP 区域的可见性问题
   - 检查 `src/index.html` 和 `src/main.js` 中"手动连接（跨网段）"区域的 HTML 结构和 CSS
   - 修复导致该区域被隐藏或遮挡的样式问题，确保其始终可见
   - 确认区域包含 IP 输入框、端口输入框（默认 8889）和"连接"按钮
   - 为 IP 输入框添加 Enter 键触发连接的事件监听
   - _需求：3.1、3.2、3.3、3.4_

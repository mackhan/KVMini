# 需求文档：权限引导强制化 & 手动连接 UI 修复

## 引言

当前存在两个用户体验问题：

1. **辅助功能权限横幅可被关闭**：用户点击 ✕ 后横幅消失，但没有辅助功能权限时键鼠捕获/注入功能完全无法使用。正确的设计应参考 OneNoteCopy：**在权限未授权之前，横幅不可关闭**，直到权限被授予为止。扫描和连接功能本身不需要辅助功能权限，不应被禁用；只有实际开始键鼠共享时才需要权限。

2. **手动连接 IP 区域在某些情况下不可见**：用户反馈手动输入 IP 连接的功能"消失了"，需要排查并确保该区域始终可见、可用。

---

## 需求

### 需求 1：辅助功能权限横幅强制化（不可关闭）

**用户故事：** 作为一名 macOS 用户，我希望在未授予辅助功能权限时看到强制性的权限引导提示，以便我知道必须先授权才能使用键鼠共享功能。

#### 验收标准

1. WHEN 应用启动且辅助功能权限为 `Denied` THEN 系统 SHALL 显示权限引导横幅，且**不显示关闭（✕）按钮**。
2. WHEN 权限横幅显示时 THEN 系统 SHALL 保持"扫描设备"和"连接"按钮**正常可用**（这两个操作不需要辅助功能权限）。
3. WHEN 用户点击"前往授权"按钮 THEN 系统 SHALL 打开 macOS 系统偏好设置的辅助功能页面。
4. WHEN 用户在系统设置中授予权限后（轮询检测到 `Granted`）THEN 系统 SHALL 自动隐藏横幅。
5. IF 当前平台为 Windows THEN 系统 SHALL 不显示权限横幅（Windows 不需要此权限）。
6. WHEN 权限横幅显示时 THEN 系统 SHALL 每 2 秒轮询一次权限状态，直到授权成功为止。

---

### 需求 2：连接成功后权限不足时的提示

**用户故事：** 作为一名 macOS 用户，我希望在连接成功但权限未授予时收到明确提示，以便我知道需要先授权才能开始键鼠共享。

#### 验收标准

1. WHEN 用户连接成功且辅助功能权限为 `Denied` THEN 系统 SHALL 在连接状态区域显示提示："需要辅助功能权限才能开始键鼠共享，请先前往授权"。
2. WHEN 上述提示显示时 THEN 系统 SHALL 禁用"开始共享"按钮，防止用户在无权限状态下触发键鼠捕获。
3. WHEN 辅助功能权限变为 `Granted` THEN 系统 SHALL 移除该提示并恢复"开始共享"按钮的可用状态。
4. IF 当前平台为 Windows THEN 系统 SHALL 不对"开始共享"按钮施加权限相关的禁用限制。

---

### 需求 3：手动连接 IP 区域始终可见

**用户故事：** 作为一名用户，我希望手动输入 IP 地址直连的功能区域始终清晰可见，以便我在跨网段场景下能快速找到并使用该功能。

#### 验收标准

1. WHEN 应用主界面加载完成 THEN 系统 SHALL 在设备列表下方显示"手动连接（跨网段）"区域，无论设备列表是否为空。
2. WHEN 手动连接区域显示时 THEN 系统 SHALL 包含 IP 输入框、端口输入框（默认 8889）和"连接"按钮。
3. WHEN 用户在 IP 输入框按下 Enter 键 THEN 系统 SHALL 触发连接操作，与点击"连接"按钮效果相同。
4. IF 手动连接区域因样式或布局问题被遮挡/隐藏 THEN 系统 SHALL 修复相关 CSS，确保该区域始终可见。

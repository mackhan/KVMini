# 需求文档：设置体验全面升级 & 功能修复

## 引言

本次迭代涵盖 5 个独立需求，来源于用户反馈的功能缺失和体验问题：

1. **tauri-commerce SDK 集成**：接入 [tauri-commerce](https://github.com/mackhan/tauri-commerce) 实现应用内购买/授权功能
2. **网卡监听优化**：当前"监听所有网卡"逻辑不清晰，用户看到多个网卡条目困惑
3. **本机指纹证书加载失败**：TLS 握手时本机证书指纹加载报错，导致连接失败
4. **显示器列表不能拖拽**：设置页中的显示器布局预览无法通过拖拽调整位置关系
5. **设置页内容过多，需分页**：当前设置面板内容堆叠，显示器布局需要独立大页面便于操作

---

## 需求

### 需求 1：集成 tauri-commerce SDK 实现应用授权/购买

**用户故事：** 作为产品所有者，我希望集成 tauri-commerce SDK，以便为 KVMini 实现应用内购买或授权验证功能。

#### 验收标准

1. WHEN 用户首次启动应用 THEN 系统 SHALL 通过 tauri-commerce SDK 检查授权状态
2. IF 用户未授权 THEN 系统 SHALL 展示购买/激活引导界面
3. IF 用户已授权 THEN 系统 SHALL 正常进入主界面，不显示购买提示
4. WHEN 用户点击购买/激活 THEN 系统 SHALL 调用 tauri-commerce 提供的支付/激活流程
5. WHEN SDK 初始化失败（网络异常等）THEN 系统 SHALL 显示友好错误提示，不阻塞主界面启动
6. IF 授权状态发生变化 THEN 系统 SHALL 实时更新 UI 状态（无需重启）

> **待确认**：tauri-commerce SDK 的具体 API 需参考 https://github.com/mackhan/tauri-commerce 手册，开发前需与用户对齐支付方式（App Store / 自定义 License Key / 其他）

### 需求 2：网卡监听逻辑优化与 UI 说明

**用户故事：** 作为用户，我希望清楚地了解"监听所有网卡"的含义，并能选择具体网卡，以便避免因多网卡导致的连接混乱。

#### 背景说明

> **为什么会有两个网卡？**
> macOS 设备通常同时存在多个网络接口：
> - `en0`：Wi-Fi 无线网卡（最常用）
> - `en1` 或 `utun0`：有线以太网、VPN 虚拟网卡、Thunderbolt 网桥等
> "监听所有网卡"意味着 KVMini 会在所有活跃网络接口上同时监听，任意一个网卡收到连接请求都会响应。这在多网卡环境下可能导致：IP 显示不一致、对端连接到错误网卡等问题。

#### 验收标准

1. WHEN 用户打开设置页"网络"分页 THEN 系统 SHALL 列出当前所有活跃网卡及其 IP 地址
2. WHEN 用户选择"自动（所有网卡）"选项 THEN 系统 SHALL 在所有活跃网卡上监听，并在 UI 上显示说明文字
3. WHEN 用户选择指定网卡 THEN 系统 SHALL 仅在该网卡对应的 IP 上监听
4. IF 选定网卡断开 THEN 系统 SHALL 显示警告提示，建议切换到其他网卡
5. WHEN 网卡列表发生变化（插拔网线、VPN 连接/断开）THEN 系统 SHALL 自动刷新网卡列表

### 需求 3：修复本机指纹证书加载失败

**用户故事：** 作为用户，我希望 KVMini 能正确加载本机 TLS 证书指纹，以便建立安全的加密连接。

#### 验收标准

1. WHEN 应用启动 THEN 系统 SHALL 成功生成或加载本机 TLS 证书，不报错
2. IF 证书文件不存在 THEN 系统 SHALL 自动生成新的自签名证书并保存
3. IF 证书文件损坏或格式错误 THEN 系统 SHALL 删除旧证书并重新生成
4. WHEN 证书加载成功 THEN 系统 SHALL 在设置页"安全"分页显示当前证书指纹（SHA-256 前 16 位）
5. WHEN 证书加载失败 THEN 系统 SHALL 在界面显示具体错误原因，并提供"重新生成证书"按钮
6. IF 对端证书指纹与本机记录不匹配 THEN 系统 SHALL 弹出确认对话框，由用户决定是否信任

### 需求 4：显示器布局支持拖拽调整

**用户故事：** 作为用户，我希望通过拖拽方式调整本机和远端显示器的相对位置关系，以便直观地设置鼠标穿越边界。

#### 验收标准

1. WHEN 用户进入"显示器布局"分页 THEN 系统 SHALL 以可视化方式展示本机和远端显示器的当前位置关系
2. WHEN 用户拖拽本机显示器图标 THEN 系统 SHALL 实时更新显示器相对位置预览
3. WHEN 用户释放拖拽 THEN 系统 SHALL 根据最终位置自动计算触发边界（左/右/上/下）
4. WHEN 拖拽结束且位置有效 THEN 系统 SHALL 自动保存布局配置，无需额外点击"保存"
5. IF 拖拽到无效位置（如完全重叠）THEN 系统 SHALL 显示视觉反馈（红色边框）并恢复到上一个有效位置
6. WHEN 显示器数量或分辨率发生变化 THEN 系统 SHALL 重新渲染布局预览，保持相对位置关系不变

### 需求 5：设置页分页重构

**用户故事：** 作为用户，我希望设置页按功能分类展示，以便快速找到需要的设置项，并有足够空间操作显示器布局。

#### 验收标准

1. WHEN 用户打开设置 THEN 系统 SHALL 展示分页导航，包含以下分页：
   - **通用**：语言、开机启动、快捷键、自动重连
   - **显示器布局**：拖拽式布局编辑器（独立大页面）
   - **网络**：监听网卡选择、端口配置
   - **安全**：证书指纹显示、重新生成证书
2. WHEN 用户切换分页 THEN 系统 SHALL 平滑切换内容区域，不重置未保存的设置
3. WHEN 用户在"显示器布局"分页 THEN 系统 SHALL 提供比当前更大的编辑区域（至少占窗口 70% 高度）
4. WHEN 用户修改任意设置项 THEN 系统 SHALL 在分页标题旁显示"未保存"标记
5. WHEN 用户点击"保存" THEN 系统 SHALL 保存当前分页的所有修改，并清除"未保存"标记
6. IF 用户关闭设置页时有未保存修改 THEN 系统 SHALL 弹出确认对话框
7. WHEN 设置页在小屏幕（< 1200px 宽）显示 THEN 系统 SHALL 自动折叠分页导航为下拉菜单

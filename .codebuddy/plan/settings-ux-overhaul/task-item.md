- [ ] 1. 设置页分页重构（基础框架）
   - 将现有设置页拆分为「通用」「显示器布局」「网络」「安全」四个分页
   - 实现分页导航组件，支持平滑切换，切换时不重置未保存状态
   - 「显示器布局」分页编辑区域高度至少占窗口 70%

- [ ] 2. 显示器布局拖拽功能

   - 实现拖拽交互：拖拽时实时更新预览，释放时自动计算触发边界（左/右/上/下）
   - 拖拽结束自动保存布局配置，无效位置（完全重叠）显示红色边框并恢复上一有效位置

- [ ] 3. 网卡监听逻辑优化与 UI

   - 选定网卡断开时显示警告提示；网卡列表变化时自动刷新
   - Rust 后端实现网卡枚举命令，前端订阅网卡变化事件
   - _需求：2.1、2.2、2.3、2.4、2.5_
